Any words. Many styles. One image.

Quote-Maker is a desktop app that sets pasted text as a finished quote image. Select a style, adjust it, and save a PNG.

Stays on your computer

Works offline, with no accounts and no telemetry. The app makes no network connections, and images are saved only where you select.

What you see is what saves

The preview, the style thumbnails and the saved PNG all come from one renderer, so the file matches the preview.

Keeps everything in one folder

Your styles and your last quote stay in a folder beside the app. Move the two together, for example to a USB drive.

The same words, set 28 ways

Every proof on this sheet uses the words in the window above. Change them, and the sheet changes too. Select a proof to open it in the window.

One style at every size

The layout adjusts to the shape. Long text shrinks to fit, and the caption says when it did.

Stars mark the words that matter

Type Start with the *best* line. The style sets the emphasis to italic, bold or colour.

28 preset styles

Five categories: Classic, Modern, Bold, Soft and Retro.

Fine-tune controls

Change the text, author and source, background, quote mark, frame and layout.

Custom styles

Save a changed style under My styles. Update it or delete it later.

24 bundled font families

They come inside the app and cover Latin characters. Other alphabets use your installed fonts.

5 image sizes

Square, Portrait, Landscape, Story, or Custom from 200 to 6000 px per side.

3 export scales

A scale of 2x makes a 2160 × 2700 px image from a size of 1080 × 1350 px.

Text that fits

Text shrinks automatically to fit the image. Empty author and source fields do not appear.

Typographic characters

Straight quotes, -- and ... change to the correct characters.

Save or copy

Save a PNG with Ctrl+S, or copy the image and paste it where you need it.

Windows x64 · .exe Runs without installation. The build is not signed, so SmartScreen can show a warning. Select More info, then Run anyway. macOS Apple Silicon · .zip Move the app out of Downloads before you open it. The build is not signed, so approve it in Privacy & Security. Intel Macs are not supported. Linux x64 · .tar.gz Install WebKitGTK first. On Ubuntu 24.04, run sudo apt install gir1.2-webkit2-4.1.

Put the app in a folder you can change, not Program Files. To build from source you need Python 3.10 or later. See the README.
